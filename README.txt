Mohamed & Nadine - Wedding Invitation (English, mobile-first)

1. Open index.html in a browser (or upload this whole folder to any web host).
2. YOUR PHOTOS (same file names, just overwrite):
   img/hero.jpg            -> photo inside the envelope at the top
   img/album-1.jpg ... album-8.jpg -> Wedding Album carousel
   (portrait photos look best; change the count with albumPhotos in js/config.js)
3. YOUR SONG: copy it into the audio/ folder and name it song.mp3
   (or change "song" in js/config.js). It starts when the envelope is tapped.
4. Names, parents, times, map, program: edit js/config.js
5. RSVP on WhatsApp: set "whatsapp" in js/config.js (e.g. 201000000000)
